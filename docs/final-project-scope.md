# Reshape your Reality
## Project Purpose
The purpose of this project is to create a professional website that serves as the digital storefront for **Reshape Your Reality**, a premium personal training business in Houston, TX. 

This website will be designed to create credibility, attract qualified leads, enable easy online booking, and support long-term client retention. 
## Project Description
This personal training website will encompass the full planning, design, development of a clean site. 

Key activities include:
- Gathering and refining brand content, messaging, and visuals from the business manager. 
- Create a professional repository on Github that houses all planning documentation. 
- Build a functional prototype with strong calls to action (free consult booking form)
## Desired Results
**The project will deliver:** 
- Consistent professional branding (logo, color palette, typography)
- Deployment ready code
- Lead-generation feature: "Book Free Consult"
- Fast Page response time

**Sucess Metrics**
- Website is approved by the business owner. 
- Project complete on time and under budget. 
- Gain 10 leads within a 60 day period. 

## Exclusions (out of scope)
- Advanced functionality (full booking system, payments, member login, blog CMS)
- Custom images or videos
- Paid advertising integration
- E-commerce or supplement store

## Feedback Loop (Communication Needs):
- **Frequency:** Weekly updates via GitHub
- **Methods:** GitHub issues, email/text for urgent items, commits
- **Key Audience:** Business Owner and Project Manager: Dominique Pohlmann
- **Escalations:** Any timeline or budget risks will be communicated within 48 hours. 

## Acceptance Criteria
- All deliverables are reviewed and formally approved. 
- The webstite meets design and functionality requirements. 
- All planning documents are complete and stored in a Github repo. 
## Constraints
- **Time** - Must launch by May 8, 2026
- **Budget** - Maximum $1200 for all efforts included
- **Resources** - Solo development
- **Scope** - Limited to two pages
- **Quality** - Clean professional website.
